# EduLite 🎓  
A minimal, elegant, and fully responsive static website template built for schools. Featuring smooth scrolling effects, modern design principles, and performance-focused code — all in a lightweight, easy-to-deploy static site.  

🚀 Perfect for schools looking for a clean, professional online presence without the overhead of a CMS.

---

## ✨ Features

- ✅ **Minimal & Clean UI**  
- ✅ **Top-notch Responsiveness** – Looks great on mobile, tablet, and desktop  
- ✅ **Smooth Scrolling Effects**  
- ✅ **SEO-Optimized Structure**  
- ✅ **Lightweight & Fast**  
- ✅ **Open Source** – Community-driven and free to use!
